# @kazekyo/nau

> ⚠️ **DEPRECATED: This package is no longer maintained.** No further updates, including security fixes, will be published. The [GitHub repository](https://github.com/kazekyo/nau) has been archived. For Relay-style pagination with Apollo Client, consider using Apollo Client's built-in [`relayStylePagination`](https://www.apollographql.com/docs/react/pagination/cursor-based#relay-style-cursor-pagination) field policy.

Nau is a tool that makes the use of [Apollo Client](https://github.com/apollographql/apollo-client) more productive for users using [Relay GraphQL Server Specification](https://relay.dev/docs/guides/graphql-server-specification) compliant backends.

The documentation site has been shut down. The source of the former documentation is available in the [repository](https://github.com/kazekyo/nau/tree/main/docs/docs).

## Installation

```sh
yarn add @kazekyo/nau
```
